CROSS-PLATFORM TESTING

Every screen matters.

Understand device emulation support before running browser journeys.

Browser engines ≠ physical devices

Playwright emulates device viewports, touch, locale, and browser engines. A Windows-labelled browser profile is not an actual Windows machine, and iPhone/iPad profiles are not physical Apple hardware. For hardware-specific bugs use a real-device testing provider.

Understand the limits of this Vercel-hosted control plane.

YOUR DATA

Stored in this browser

Campaigns and diagnostics remain in local storage on this device. They are not synced to an account, shared with other devices, or stored in a production database.

EXECUTION

Real browser worker

Vercel runs the UI and a safe single-request diagnostic. The optional Playwright worker runs from a local machine or separately hosted VM after a domain ownership check.

node worker/run.mjs ./plan.json

True regional IP testing requires workers in the actual countries—never just an altered locale or timezone.

SECURITY

Domain ownership proof

Each target needs a matching verification file at /.well-known/visitorlab-verify.txt. Redirects, private network destinations and unverified domains are refused by the live diagnostic endpoint.

ETHICAL TESTING

Transparent synthetic traffic

We mark automated traffic, block common analytics requests in the browser worker, limit concurrency, and avoid fabricated referrals, rankings, ad interactions and bot-detection evasion.
